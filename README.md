# 청년센터 새글 알리미

내 아이폰에서만 쓰는 개인용 웹앱이에요. GitHub Pages에 올려서 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 1. GitHub Pages에 올리기

1. github.com 에서 새 저장소(Repository)를 하나 만듭니다. (Public이어도 상관없어요 — 그냥 청년센터 게시판 링크를 보여주는 페이지라 민감한 정보가 없습니다.)
   - 예: `youth-alert`
2. 이 폴더 안의 4개 파일(`index.html`, `manifest.json`, `icon-180.png`, `icon-512.png`)을 저장소에 업로드합니다.
   - GitHub 웹사이트에서 저장소 페이지 → "Add file" → "Upload files" → 파일 4개를 끌어다 놓고 "Commit changes"
3. 저장소의 **Settings → Pages** 로 들어갑니다.
4. "Branch"를 `main` (또는 `master`), 폴더는 `/ (root)`로 선택하고 저장합니다.
5. 1~2분 기다리면 `https://내깃허브아이디.github.io/저장소이름/` 주소가 생깁니다.

## 2. 아이폰에서 홈 화면에 추가하기

1. 아이폰 Safari로 위 주소에 접속합니다. (⚠️ 꼭 Safari여야 해요. 크롬 등 다른 브라우저는 "홈 화면에 추가"가 제대로 안 될 수 있어요.)
2. 하단 공유 버튼(⬆️) 탭 → "홈 화면에 추가" 선택
3. 홈 화면에 생긴 아이콘으로 실행하면 앱처럼 전체화면으로 열립니다.

## 3. 알림 켜기

- 앱을 홈 화면 아이콘으로 실행한 상태에서 (Safari 탭이 아니라!) 상단의 "🔕 알림 켜기" 버튼을 누르고 허용해주세요.
- 아이폰의 웹앱 알림은 **홈 화면에 추가해서 앱처럼 실행할 때만** 정상 작동합니다. 그냥 Safari 탭에서는 알림이 안 뜰 수 있어요.

## 4. 사용법

- 앱을 열면 자동으로 새 글을 확인하고, 상단 "🔄 지금 새 글 확인" 버튼으로 언제든 수동 확인할 수 있어요.
- 앱을 열어둔 동안은 10분마다 자동으로 확인합니다.
- 완전히 꺼둔 상태에서는 확인하지 않으니, 가끔 앱을 열어주는 습관이 필요해요.
- "새 글 피드"에서 글을 탭하면 해당 사이트로 이동합니다.

## 5. 사이트별 지원 상태

| 사이트 | 자동 새 글 감지 |
|---|---|
| 젬프 (대구청년센터) | ✅ 정상 지원 |
| 남구청년센터 | ✅ 정상 지원 |
| 북구청년센터 (공지/모집중) | ⚠️ 새 글은 감지하지만, 클릭 시 목록 페이지로만 이동 (개별 글 링크 없음) |
| 동구청년센터 | ❌ 바로가기만 (자바스크립트 사이트) |
| 북성로청년센터 | ❌ 바로가기만 (자바스크립트 사이트) |
| 수성구청년센터 | ❌ 바로가기만 (봇 차단 보안 절차) |

나중에 동구/북성로/수성구 사이트도 구조를 더 파보면 지원을 추가할 수 있어요.

## 6. 참고 / 한계

- 무료 CORS 프록시(`allorigins.win`)를 통해 사이트 내용을 가져와요. 이 프록시가 가끔 느리거나 일시적으로 안 될 수 있어요. 그럴 땐 "확인 실패"로 표시되고, 다음 확인 때 다시 시도합니다.
- 모든 데이터(어떤 글을 봤는지 등)는 이 아이폰의 브라우저 안에만 저장돼요. 다른 기기와 공유되지 않고, 서버에도 전송되지 않아요.
- 앱을 지우거나 Safari 데이터를 초기화하면 "이미 본 글" 기록도 같이 사라져요.
